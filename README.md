# LH Skill Toolset

> Skills = nouns. Primitives = verbs. Agent = executor.

An evidence-first skill contract library for Forward Deployed Engineering (FDE).

## Operating loop

`Reality → Understand → Investigate → Verify → Implement → Own Outcome`

## Taxonomy

- Reality: repo-map, trace-flow, inspect-runtime
- Investigation: reproduce, hypothesize, verify
- Intervention: patch, test, deploy
- Ownership: validate, document

## Core invariant

An agent establishes evidence before mutation. Passing tests alone does not establish production correctness.

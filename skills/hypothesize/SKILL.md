# hypothesize

## Purpose
Generate explicit, testable explanations for an observed failure or gap.

## MUST
- Start from observed evidence.
- State each hypothesis and the evidence supporting it.
- Define what evidence would confirm or reject it.
- Keep multiple plausible hypotheses when uncertainty remains.

## MUST NOT
- Present a hypothesis as a fact.
- Patch before the cause is sufficiently verified.
- Collapse unknowns into assumptions.

## Output
`Observation → Hypothesis → Supporting evidence → Falsifier → Verification plan`
